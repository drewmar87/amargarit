Accessibility & WCAG 2.0 Annotations Spring 2026 · Awareness & Attempt

This portfolio was authored with WCAG 2.0 Level AA principles in mind, organized around the four POUR pillars: Perceivable, Operable, Understandable, and Robust. The list below documents specific awareness and attempts; this is a working draft, and improvements continue as I learn.

Perceivable

  • Descriptive alt text on every meaningful image
  • aria-hidden="true" on decorative Font Awesome icons
  • High-contrast palette (dark navy, blue, white) checked against AA contrast minimums
  • Text scales with user browser settings; no fixed pixel locks on body copy
  • Carousel content also announced via aria-live="polite"

Operable

  • Skip-to-main-content link is the first focusable element
  • Full keyboard navigation: Tab order, Enter/Space activation, ←/→/Home/End on carousel
  • Visible :focus-visible outline rings on all interactive elements
  • No auto-advancing carousel and no flashing or seizure-inducing motion
  • Touch swipe support layered on top of, not replacing, button controls

Understandable

  • Semantic HTML5 landmarks: header, aside, nav, section, article, footer
  • Logical heading hierarchy (h1 → h2 → h3) with no skipped levels
  • Form fields paired with visible <label> via for/id; autocomplete tokens supplied
  • Plain-language copy and predictable navigation patterns
  • Error/status messaging announced through an aria-live status region

Robust

  • Valid HTML5 with appropriate ARIA roles (region, tablist, tab, group, complementary)
  • Carousel implements aria-roledescription="carousel" with state managed via aria-selected
  • Tested against current major screen readers (VoiceOver, NVDA) for landmark navigation
  • Responsive layout adapts at 1100px and 640px breakpoints — phone, tablet, and desktop
  • External links carry rel="noopener noreferrer" and an "opens in new tab" cue

Reference: U-M LSA Web Accessibility Guidelines & Best Practices — used as a checklist while building this portfolio. WCAG 2.0 awareness and attempts noted above; ongoing improvements expected as the body of work grows.
